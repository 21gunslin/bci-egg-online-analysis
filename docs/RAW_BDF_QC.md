# 原始BDF质控与FIF导出

这是独立入口，不使用现有特征计算的滤波、降采样、重参考与剔除流程。

## 使用顺序

1. 打开“原始BDF → 质控 / FIF”，选择BDF，可选RecordInfo配置。
2. 首次可不填人工标记；点击读取，获得实际电极模板图、独立的64导参考图、全通道全频Welch谱、枕区PSD与表格。
3. 选择通道与起止秒数检视原始波形。EEG从额区排至枕区，辅助/参考信号分组。默认按当前窗全部原始幅度逐通道适配纵轴，右侧标注每格幅度、实际范围和原始中心；相同图上高度不表示相同振幅。需要比较振幅时切换“同单位统一自适应”；需要固定尺度时选“手动电压标尺”，默认为100 µV/格，可直接修改。没有对原始数据做归一化或改单位。
4. 初始时间窗按前10秒若干EEG通道的主导频率建议，强50 Hz成分常建议约1秒以看清振荡；这只是显示建议，不判定脑节律或临床状态。可输入任意有效起点/窗长、选整份记录概览、放大单通道。滚轮调纵轴，Shift＋滚轮围绕鼠标缩放时间，拖动波形平移时间，双击或点“纵轴适配当前窗”恢复适配。静态图片点开后也可滚轮放大、拖动平移、双击恢复。
5. 将确认的坏道、坏段写入草稿；可以点通道旁的坏道按钮。按真实记录填写睁闭眼时段，未确认时留空。
6. 点击“应用当前标记，生成新版本FIF”。旧文件保留，下载链接对应当前生成版本。检查结束后使用最新版本。

## 仅调整查看，不重新处理数据

### 看不完整份记录时：辅助巡检

先载入/恢复BDF，点击“扫描全记录，生成候选定位”。程序按时间窗计算原始波形的平线、数字边界、跳变、相对幅度离群、基线突变及强50/60 Hz成分提示。它不滤波、不自动剔除或写BAD，也不是MNE官方自动伪迹分类器；阈值是本工具的启发式候选规则，可能漏检和误报，不能仅按候选结果判为正常或确定伪迹原因。

全记录×通道概览中，灰色只表示未触发程序规则，橙红表示候选。点击格子或列表中的候选可直接跳到原始通道和前后文。短暂异常优先排列；相同原因覆盖≥80%时间窗时合并成持续性通道提示，避免列表被重复报警塞满。持续性提示的时间包络可能包含间隙，不意味着包络内每个采样点都异常。详细规则与候选CSV可在网页查看。

波形默认每页4通道，可改为8、16或全部所选。“下一巡查页”先遍历当前时间窗的所有通道页，再前进时间。自动翻页可以暂停，不自动计入人工复核。它帮助浏览，不证明已经观察完全部细节；长窗仍是min/max显示包络，必要时缩短时间放大。

只有点击“本页已复核”或“本页需再看”，才登记实际显示的通道与原始起止时间。人工浏览覆盖按通道·秒的区间并集计算，重叠和重复登记不重复计数；只看过半个扫描窗，就只算半个窗。需再看表示已经浏览但仍有疑问，覆盖率不是清洁数据比例。蓝框表示人工覆盖完整单元，浅蓝框表示部分覆盖。

人工进度存放于对应缓存的独立`manual_review_state.json`，可以恢复、撤销上一笔并导出CSV。它不会自动变成`info['bads']`或`BAD_`注释。确认后如需标坏道/坏段，仍应在原有人工标记区域明确填写，再单独选择FIF导出。源BDF和已有FIF不变。

巡检方法背景：[MNE伪迹检视](https://mne.tools/stable/auto_tutorials/preprocessing/10_preprocessing_overview.html)。本工具的规则和阈值未经过本队列专家标签验证；辅助/参考信号的固有尖峰或固定状态不能直接当作EEG伪迹。

新文件可以使用“只载入BDF查看（不导出FIF）”：只读取头信息、事件和查看需要的采样窗口，估计显示参数，不运行完整特征/PSD质控，也不导出FIF。后续确有需要时再选择完整质控或FIF导出。

已有结果可点击“恢复已有结果，仅调整查看”。优先恢复本浏览器上次的结果；没有本地记录时恢复本机最近完成的一份原始质控结果。恢复不调用分析流程、不重写源BDF/FIF，已有图片仍使用当时的设置。

“只导出当前视图”另建结果目录，仅输出当前窗口PNG与坐标参数CSV，不生成或修改FIF。单通道模式导出该通道，多通道模式导出当前显示的所选通道。图片中的坏道/坏段采用已保存版本的标记；草稿需在正式导出FIF前另行应用。

自适应范围使用当前窗口全部原始采样点的最小/最大值和中位中心，再向1/2/5×10的幂次取整并留余量；不通过剔除极值让图变漂亮。大瞬态仍可能压缩其余细节，可缩短时间窗。平线不会被变成波动。手动增益放大后超界会标注，裁切只发生在绘图中。查看表保留原始最小/最大/均值/标准差/峰峰值与显示坐标范围；长窗的min/max包络仅用于屏幕显示，短窗重新读取原始采样，不对原数据重采样。

同目录`fdata.fif`保存和BDF/FIF互斥导入参见[FIF导入导出说明](FIF_IMPORT_EXPORT.md)。旧版同名导出先备份到`.fdata_versions`，再更新；原BDF不变。

## 保留与标记

- 保留所有非注释信号，包括EEG、辅助信号和完整Status字序列；不做触发位掩码。TAL事件转为MNE注释。
- BDF数字值按头部物理标定解码。电压单位转成SI伏特，不额外除以1000。未知单位保留其标定数值并标misc，不伪装成EEG。
- 未声明电压单位且物理上下限退化的通道保留原始数字计数，明确写入通道标定表。电压标定退化则报错，不猜测倍率。
- 混合采样率分别导出FIF，保持每组原始采样数；不可把低速通道静默上采样。各组起点均是源BDF首样本时间。原通道顺序见CSV。
- 模板为标准10–20含扩展点位，head坐标、米；非个体实测。未确认名称不装配，保留原名和信号，坐标留空。64导图是指定的64个模板点参考，不是设备导线编号或本次采集通道数。
- 坏道写`info['bads']`，坏段写`BAD_...`，均不删数据。`BAD_ACQ_SKIP`会触发MNE保存跳过样本，故转为`BAD_source_acquisition_skip`，原文保存在extras。
- FIF使用双精度，保存后逐块比对所有样本，并核对通道、采样率、类型、坏道、注释、坐标。
- MNE 1.13.2的FIF字符串对非Latin1文字转义。完整标签、精确注释起止秒数存于标准`Annotations.extras`（JSON字段）；CSV也保留原文。FIF自身的普通注释时间与坐标存在格式精度限制。
- 未确认时区，不伪造UTC：源文件头日期/时刻原文留在Info描述与汇总；FIF的meas_date为空，按相对时间切片。
- 截断、重复空通道名、损坏标定及BDF+D/注释时间缺口明确报错，不以静默裁剪替代保留。
- 原BDF是档案源文件，应另行保留。FIF不是逐字节BDF副本，也不能恢复采集设备已经施加的硬件滤波。

## 图表与指标

### 原始检视中的黄色按钮与频域

黄色扫描旁的绿色“填入人工标记草稿”使用本次**全部扫描候选**，不受列表页码/候选筛选条件影响。持续性通道提示（按当前规则为同原因触发≥80%窗口）写入坏道草稿；短暂候选按真实扫描起止时间写入坏段草稿并附通道和原因，不使用跳转波形的上下文范围，也不把持续性提示的时间包络写成整份坏段。

绿色按钮保留已有手工内容，重复点击不会反复追加已存在通道或已覆盖时段；同一时间段的多个原因合并。填入后自动展开并定位“人工标记与电极装配”，可直接删除或补充。眼状态和电极装配映射不被自动填写或改动。草稿只是待核候选，不代表人工确认；若全部EEG被列为坏道，会提示先删改。坏段草稿导出后作用于全部通道，原因中的通道名只是复核线索，不能把它当作通道特异注释。

填入本身不发送导出请求、不修改BDF/FIF、不增加人工浏览覆盖率；确认草稿后再单独点击应用标记生成FIF。未完成本记录扫描时绿色按钮禁用；扫描阈值、分窗或范围已变化时须重新扫描。超过1000条坏段或草稿请求大小限制会明确报错，不部分覆盖原内容。计算方法版本仍为0.10.0，可继续使用原缓存。

载入或恢复记录后，点击黄色“自动红标并定位可疑通道/波形”：按当前巡检参数扫描全记录，红标候选通道与实际触发的时间窗，跳到首个候选的原始波形，并显示同一通道、同一上下文窗口的PSD。深色背景突出当前选中的候选区间。用“下一个候选”继续核对。“清除候选红标”只清除程序提示，保留已确认的BAD标记。自动定位不会计入人工复核覆盖率。

红色的“候选待核”并非已确认坏道。已保存的人工坏道另标为“已保存BAD”；候选规则未经过本队列专家标签验证，不能替代人工核查，也不自动删道删段或写入FIF。

波形下方“频域检视”可选择当前页、全部EEG、全部信号（最多64通道）或指定单通道；选择当前原始窗口或整份记录，设置频率上下限和Welch窗长，再点击“读取/更新频域”。“查看频域 PSD”直接展开并定位该面板。开启跟随后，原始窗口及候选跳转会更新PSD；整份记录模式不随时间重算。黄色按钮会切回当前窗口/当前通道并开启跟随，以便核对同一候选。

PSD直接使用原始采样值：Hann窗、50%重叠、`detrend=False`、不补零；不滤波、不陷波、不去均值、不重参考。包含原始坏道和坏段。保持各通道原采样率，异单位分图，频率不超过各自Nyquist；输入的频率上下限只是谱图范围，不是滤波截止频率。当前窗口短于设定Welch窗时按可用样本缩短，并报告实际分辨率。较大直流偏置可影响最低频点，短窗无法分辨很低的频率，均不应直接解释为脑节律。

可切换dB/线性功率显示。dB图最多显示120 dB动态范围，极低或零功率仅在绘图时落到图底；平线单独提示。“导出当前PSD数值”另建目录保存线性功率CSV、时间范围与Welch参数，数值不作该显示截底。50/60 Hz虚线及突出度数值便于查找工频候选；原始均值/标准差采用曲线对应的信号单位，PSD采用该单位平方/Hz。原始BDF和已有FIF不被重写。

### 完整质控输出

全记录Welch为Hann窗、50%重叠、`detrend=False`、不补零，从0至Nyquist；显示包括人工坏道/坏段。FFT末端不满一窗的部分不参与该PSD估计，但保留在FIF。所有实际窗长/窗数/分辨率见表。不同物理单位分别画图，不能将计数谱当µV²/Hz。

50/60 Hz相对两侧2–5 Hz邻域中位PSD突出超过10 dB只提示复核。虚线还标出谐波；全谱形状图与离群评分仅供找候选。平坦/边界占比/频谱形状评分均不会自动变成坏道。

枕区图现在为**平均功率谱**：对实际可确认且单位明确、未标为坏道的O1/Oz/O2逐通道计算Welch PSD，再对线性功率等权平均。既不先平均波形（会因相位抵消），也不对dB求平均。左图展示全记录平均谱（含BAD时段），右图展示0.5–30 Hz线性功率谱；有手工眼状态时分别展示睁眼、闭眼平均谱。状态区间在每通道内按Welch窗数加权，再对通道等权平均，睁闭眼两种状态使用相同共同通道。不同原采样率分组显示，不插值原始信号或PSD；无标签不自动判断状态，已填写但无有效窗时不使用全记录冒充状态谱。下载“枕区平均功率谱_数值.csv”和“枕区平均功率谱_α峰.csv”可复算图中均值与峰值。

α峰的8–13 Hz局部峰须在全谱中达到3 dB prominence，未达到记缺失。逐段表与逐通道眼状态α峰表继续保留，另附平均谱α峰。状态α分析避开人工/源BAD区间，不跨坏段拼窗，不使用确认坏道；短于设定Welch窗的清洁余段不补齐。区间数或窗数很少时比较不稳定，未检出不等于临床异常。无眼状态标签时不把“未评估”记成“未检出”。

## 后续切片

下载同一组所有FIF分卷到同一目录后，使用第一卷：

```python
import mne
raw = mne.io.read_raw_fif('group1_1000Hz_raw.fif', preload=False)
print(raw.info['bads'])
print(raw.get_montage())
print(raw.annotations)
# 中文原文和精确时间（不要只依赖description显示）
for annotation in raw.annotations.extras:
    print(dict(annotation))
# 按实际研究设计决定事件、切片、是否拒绝BAD；本导出尚未删段。
epochs = mne.make_fixed_length_epochs(raw, duration=2, reject_by_annotation=True,
                                     preload=True)
```

`reject_by_annotation=True`是后续切片时的显式选择。当前导出的Raw仍保留坏段；普通Epochs的坏道处理应根据分析方法另行决定。程序不提供产后抑郁或其他疾病诊断。

原始上传缓存和JSON配置仅存本机results目录，不作为下载文件公开，也不得提交到GitHub。重新导出会保留新旧版本及源BDF缓存，需自行规划磁盘空间。

API依据：[MNE Raw](https://mne.tools/stable/generated/mne.io.Raw.html)、[Annotations](https://mne.tools/stable/generated/mne.Annotations.html)、[BDF混合采样率行为](https://mne.tools/stable/generated/mne.io.read_raw_bdf.html)。
