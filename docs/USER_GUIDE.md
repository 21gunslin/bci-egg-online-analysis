# 脑电特征网页使用说明

## 启动

双击 `scripts\启动脑电特征网页.bat`。它会启动独立的本机后台服务并打开浏览器页面 `http://127.0.0.1:8765/`。服务启动器会先检查健康状态，已启动时不会重复运行；启动失败会显示错误日志位置。

需要停止服务时，双击 `scripts\停止脑电特征网页.bat`。服务日志位于 `results\eeg_web_output\server.log` 和 `server_error.log`。电脑关机或注销后，再次使用时双击启动器即可。

## 使用

在网页中选择一个 BDF、EDF 或 GDF 文件，设置目标采样率、工频陷波和分段长度，勾选要计算的特征，点击“开始本地分析”。默认预处理使用 0.5–45 Hz 四阶 Butterworth 带通及 SOS 双向零相位滤波；目标采样率至少设为 100 Hz。完成后可下载 Excel 汇总、CSV 特征表、分析报告和图表。输出保存在 `results\eeg_web_output` 下，每次分析单独建目录。

网页和服务只绑定到 `127.0.0.1`，数据在本机处理，不会发送到互联网。支持单个文件，当前上传上限为 2 GB。首次使用若浏览器打不开，可等待数秒后刷新；若 8765 端口已被占用，请先关闭旧服务窗口再启动。

## 环境

启动器优先使用 Codex/DSH 随附 Python 运行环境；否则使用系统 Python。引擎依赖 NumPy、SciPy、Pandas、Matplotlib、OpenPyXL。

## 新增：分娩镇痛前后 EEG 对比
打开“镇痛前后 EEG 对比”，选择同一受试者镇痛前、后的 data.bdf，核对顺序并勾选确认。系统使用统一预处理设置，取两份记录的共同质控通道和相同有效时长，重算四域特征。表格提供 A、B、B−A 和相对变化，可按特征域及名称筛选。

时域使用同一通道和纵轴；时频图使用同一通道和色标；频谱可直接叠加查看；各频段 PLV 展示 A、B 和差值矩阵。通道选择器可复用缓存重新绘图。时间是质控片段拼接时间，不能用于对齐宫缩；差值不是镇痛因果效应或 PPD 诊断。电压按文件头单位换算，文件头误标时需先确认来源。

## 新增：spike 独立分析
此数据文件夹的 spike.bdf 为单通道 spike、1 Hz、pcs 单位的设备计数，不是多通道 EEG 波形。仅上传该文件时，显示逐秒计数、计数总和、每分钟计数及时间分布；通道、区域和慢波标为无法评估。

可另选同一记录段文件夹中的 data.bdf。系统核对文件头开始时间和时长，保留原始时间轴，在设备标记秒内（也可选全记录）寻找候选窄峰并筛查后续慢波。此流程与常规 0.5–45 Hz EEG 分析分开，采用 0.5–70 Hz 复核信号及 5–70 Hz 候选检测，不删除短暂片段。原始采样率须至少 200 Hz。

显示通道、对应头皮区、左右侧、候选发生率及慢波规则结果；50 ms 内跨通道峰合并为事件组，区域统计仍按通道计数。每分钟候选数以整段记录时长为分母。网页最多显示 200 个事件、500 行通道明细，完整 CSV 可下载。电极对应头皮区不等于脑内起源定位。候选检测尚无本队列专家标签验证，不能据此诊断癫痫；未满足慢波阈值不等于临床无慢波。

额外电压修正默认 ×1；仅确认设备导出存在单位误标后选择 ×0.001 或 ×1000。不要为了得到期望结果修改倍率。所有图表点击可放大，也可新窗口查看原图。

配对缓存仅保存于本机 results/eeg_web_output，用于切换通道重绘；网页下载接口不开放缓存和分析清单。分析串行执行，重复提交会提示等待。重启电脑后请双击 scripts/启动脑电特征网页.bat，再访问 http://127.0.0.1:8765/。


## 0.2.0 审查后的方法约定

- 文件声明的 V/mV/µV/nV 在片段质控前统一为 µV；未知单位直接报错，不推断设备误标。
- 自动 EEG 选择使用已知电极名称，未知通道、参考通道和设备计数不自动纳入。关闭自动选择不代表其通道类型已经验证。
- 分段按实际分析采样率计算。保留采集参考，不推测参考电极或坐标；任何组间、前后比较前仍需确认采集参考一致。
- 滤波参数保持 `butter(N=4, [0.5,45], btype='bandpass')` + `sosfiltfilt`。这里 N 是原型阶数，带通单程为8阶，双向有效16阶；合成幅频响应是单程的平方，截止点约 −6 dB。参数未因文字修订而改变。
- 修正绝对功率积分、Hjorth 复杂度与 PLV 相位抽样；旧结果应重新计算，不能与新版本直接混用。比较入口会拒绝旧方法版本缓存。
- GDF 委托 MNE 读取，需安装 `requirements-mne.txt` 的可选依赖；尚未用真实 GDF 样本验收。BDF/EDF 默认保留原读取器。
- 当前仍将质控后片段拼接计算探索性特征。跨坏段的时频、相位及导数存在边界效应；注释中的 BAD 片段未自动应用。这两项解决前，不应声称达到正式预测建模所需的完整预处理标准。

审查细节见 [MNE 审查报告](MNE_REVIEW.md)。


## 0.3.0：可选 evt.bdf 事件标记

三个分析入口均可勾选“使用 evt.bdf 事件标记”。单份 EEG 和 spike 入口选择一份配套事件文件；前后对比可分别选择 A、B 的 evt，至少选一份。取消勾选后按原流程分析。

事件使用 BDF Annotations 的 TAL 起点、持续时间与 UTF-8 原始描述。空描述的时间保持标记不算事件；不把 KeyIn:253 等编码自动解释为宫缩、镇痛或棘波，也不把两个同码事件自动配对成区间。

相对本段时间 = evt 原始起点 + evt 文件头开始时间 − 参考记录文件头开始时间 + 额外校正偏移。参考为单份/对比 EEG；spike 若提供配套 EEG 则参考 EEG，否则参考1 Hz计数序列。只有明确设备时钟偏差时才填写额外偏移。

结果增加事件标签计数、时间轴、起点在本段内/区间与本段重叠/本段外的状态、原始样本索引和 CSV 下载。单份/配对还根据原始质控片段索引标明起点是否保留，并给出保留起点的有效拼接时间。

事件文件可能覆盖整次记录，即使只有少量注释数据记录，其事件起点也可在几百秒后。选择较短的 data.bdf 时可能没有任何事件落在其中，系统会明确显示0，而不会强行平移。文件头时钟通常只有秒级精度，本功能未验证亚秒级硬件同步。事件仅用于独立定位，不自动改变特征、不重新切段、不生成 ERP；持续事件的质控状态只描述起点。

单个 evt 文件最大20 MB；页面最多展示1000个事件，完整明细在CSV中。标识不匹配、时间缺失、注释编码错误或记录截断时会拒绝自动对齐。
