# 架构与方法边界

浏览器通过本机 HTTP API 发送选择的文件。服务只监听 `127.0.0.1:8765`，分析操作串行执行；结果保存在本机 `results/eeg_web_output/`。无需第三方分析服务。

## 程序

- `eeg_feature_engine.py`：文件读取、预处理、四域特征和单份报告。
- `eeg_pair_spike.py`：共同通道与等时长比较；计数型 spike 及原始波形候选检测。
- `eeg_web_extra.py`：配对缓存、上传令牌与新增 API 路由。
- `eeg_web_server.py`：静态页面、健康检查、分析入口、下载与私有缓存访问限制。

## 接口

| 路径 | 作用 |
|---|---|
| `GET /health` | 服务健康与版本 |
| `POST /api/analyze` | 单份分析；对比模式可保存私有预处理缓存 |
| `POST /api/compare` | 使用两个已有缓存重新计算配对特征 |
| `POST /api/upload` | 暂存计数型 spike 或配套 EEG |
| `POST /api/spike` | 独立计数/候选波形复核 |
| `GET /preview/{run}/{file}` | PNG 原图预览 |
| `GET /download/{run}/{file}` | 导出 PNG/CSV/XLSX/TXT |

## 解释限制

- 前后标签须与真实镇痛时间核对。有效片段拼接时间不能用于宫缩同步。
- 比较使用固定共同通道；不同通道覆盖的旧结果不能直接当作配对变化。
- 文件单位按文件头解释，设备误标必须有依据才能修正。
- 单通道 1 Hz spike 是设备计数，不包含电极信息。配套 EEG 的候选检测为启发式，未通过专家标签验证。
- 对应头皮区域不是脑内源定位；本程序没有已验证的产后抑郁个体预测模型。
- 只用于本机。不要将现有开发服务直接暴露到公网。
