# MNE-Python 代码与可用性审查

日期：2026-10-27。审查基线：`9061fe0`；修正方法版本：`0.2.0`。

## 结论

当前程序可以作为本机探索性 EEG 特征工作台。若要形成论文最终特征或 PPD 预测训练集，仍需解决下述采集标定、参考、注释与拼接边界问题，不能把“代码能运行”表述为“临床预测有效”。本次使用 MNE 作独立对照；BDF/EDF 主流程仍是已对照验证的 SciPy 实现，并非已完整迁移为 MNE。

## 已修正的问题

| 级别 | 原问题及影响 | 修正 |
|---|---|---|
| P1 | V/mV/nV 未在单份分析质控前统一，µV 阈值和图轴可能失真 | 新增明确单位转换；未知单位报错，不推测设备误标 |
| P1 | 分段使用目标采样率；源采样率低于目标值时，片段长度错误 | 使用实际分析采样率；过短记录返回正确的空三维 epochs |
| P1 | 通道质控表按保留列表的位置索引原通道，可能错标通道 | 按原始保留索引输出，增加通道标签一致性测试 |
| P1 | Hjorth complexity 缺少除以 mobility | 按标准比值定义修正；旧结果需重算 |
| P1 | PSD 绝对功率缺少频率步长，量纲与分辨率不一致 | PSD × Δf 积分；相对功率分母明确为 0.5–45 Hz 总功率 |
| P1 | PLV 在求 Hilbert 相位前直接稀疏抽取波形 | 改为全采样率求相位后再均匀抽样；网络带通改用 SOS |
| P1 | 未知通道自动视作 EEG；没有 EEG 时还回退到全部通道 | 自动选择限于已识别电极名称；不再回退到计数、参考或未知通道 |
| P1 | 自写 GDF 解析把二进制 GDF 当 EDF 风格 ASCII 字段处理 | 改由可选 `mne.io.read_raw_gdf` 公共 API 读取；尚无真实 GDF 验收 |
| P1 | 非有限值静默置零；不连续记录按连续记录解释 | 非有限值报错；不连续 EDF+D/BDF+D 明确拒绝 |
| P2 | 科学计数法记录时长可能被截为整数部分 | 解析完整浮点字符串；无效时长不能猜为 1 秒 |
| P2 | 参考、软件版本、原始保留片段索引缺少记录 | 报告/清单记录版本、参数、单位、参考未验证状态、片段索引；缓存按方法版本区分 |
| P2 | 图轴未明确拼接时间；单份 PLV 图使用变化色标 | 明确有效片段拼接时间；PLV 固定 0–1 色标 |

滤波数值参数没有为迎合结果而改动。仍使用 `butter(N=4, [0.5,45], btype='bandpass', output='sos')` 与 `sosfiltfilt`。N=4 为原型阶数，带通变换单程为8阶，前后向有效16阶；合成幅频响应为 |H|²，不能写成“幅频响应不变”。参考 [SciPy butter](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.butter.html) 与 [MNE IIR phase](https://mne.tools/stable/generated/mne.filter.filter_data.html)。

## 真实和合成数据对照

使用独立 `.venv-mne-review`：Python 3.12.14、MNE 1.13.2、NumPy 2.3.5。依赖只安装于该环境；常规网站的运行环境没有被替换。

- 合成 BDF 以及本机数据集中三份不同的真实 BDF：采样率、样本数与共同 EEG 通道数据一致；真实数据最大绝对误差约 1.2×10⁻¹⁰ µV。
- 匹配 Butterworth 设计、IIR 零相位及 27 样本边界填充后：SciPy 与 `mne.filter.filter_data` 输出一致。MNE 默认 padding 与此测试设置可能不同，不能直接逐点比较默认结果。
- 匹配 Hann 窗、FFT 长度、片段长度、50% 重叠与去直流后：Welch PSD 与 `mne.time_frequency.psd_array_welch` 一致；积分 α 功率一致。
- 实际 200 Hz、请求目标 250 Hz 的固定 2 秒分段：与 MNE 分段一致，每片段400点。
- 三份真实记录默认预处理均可运行，保留通道数为10–12。这里只检查流程可执行，不等于这些通道已获专家质量认可。
- 13 项回归测试全部通过，覆盖上述数学/单位/时间问题、计数不伪造空间发现、合成窄峰及慢波、相同配对零差值、本机接口和缓存下载隔离。

对照工具：`tools/mne_parity_review.py`。实际记录文件路径、身份信息及原始波形不写入公共报告。详细本机测量值保存在忽略的 `results/mne_review/`，不上传。

本机已有 MNE 配置文件无法以 MNE 所需模式打开；本次验证通过进程级独立配置目录运行，未改动原配置文件权限。此项属于运行环境问题，不是 EEG 结论。

## 尚未解决，正式科研前必须处理

1. **P1：坏段拼接的边界。** 当前保留 epochs 拼接后计算时频、导数及再滤波相位，可能产生人工跳变。已记录原始片段索引并提示风险，但尚未改为在连续保留段/epochs 内计算后按预定规则聚合。该问题未因 MNE 读取对照通过而解决。
2. **P1：BAD 注释和事件时间。** EDF/BDF 注释仍以文本导出，未完整按 onset/duration 应用坏段排除，不支持据此直接作事件锁定 ERP。GDF 的 MNE 读取保留带时间文本，但也未自动建立 ERP epochs。
3. **P1：设备单位误标与参考未知。** MNE 对照只能证明双方遵循同一文件头，不能证明文件头是真实物理标定。抽查记录的声明为 uV、物理范围很大；需从设备说明、导出设置或采集者确认。不能为增加有效通道数而自动除以1000。未确认参考时保留采集参考，不擅自平均参考或推断坐标。
4. **P1：伪迹与 spike 有效性。** 自动阈值不代表眼动、肌电或运动伪迹已清除；spike 仍为未经专家标签验证的启发式候选。对应电极区不等于源定位。
5. **P2：时频 burst ratio。** 每条记录自身第90百分位作为阈值，使比例通常接近10%，不能作为稳定的疾病特异事件发生率；需要独立定义事件阈值和验证。
6. **P2：完整格式和规模验收。** 真实验证仅覆盖抽查 BDF；未覆盖真实 EDF/GDF、所有混采样率组合、2 GB 上限与所有异常注释。混采样率自写 BDF 读取器会跳过非主采样率通道，MNE 会重采样，应在该场景另外验收。
7. **P2：代码风格。** 已移除 GDF 错误解析及新增测试，但部分历史 HTTP/绘图代码仍使用密集分号和较长函数。尚未完成全量 PEP 8/静态类型检查；不能把本报告当作风格审查全通过证明。

## 对后续 PPD 研究的影响

版本变化会改变部分功率、复杂度和质控结果。正式训练前应固定方法、验证关键脑区覆盖、确认镇痛时间和参考，再重建全队列特征。严禁混用不同版本缓存、把同一产妇的不同片段分入训练与测试两侧，或把本次软件验收当作预测效能证据。
